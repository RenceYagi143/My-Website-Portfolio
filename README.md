# Terence Jay Eborda – Portfolio

Vite + plain JavaScript, Three.js (3D background) and GSAP (animations).

## Run locally
```
npm install
npm run dev
```
Open the address it prints (usually http://localhost:5173).

## Add your pictures
Put files in `public/images/` using the exact names listed in each section's `*.data.js`
(for example `public/images/awards/01-champion-robothon-region-x.jpg`).
A missing picture simply shows a labeled placeholder.

## Edit content
Each section folder has a `*.data.js` file. Change the text there; no layout code needs to be touched.
Colors live in `src/styles/variables.css`.

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. On vercel.com choose Add New → Project, import the repository.
3. Framework Preset: Vite. Build command `npm run build`, output directory `dist` (auto-detected).
4. Click Deploy. Every `git push` after that redeploys automatically.
